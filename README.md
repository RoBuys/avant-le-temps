# Avant le temps

Site interactif de cosmologie quantique, d'après *L'origine du temps* de Thomas Hertog : équations de Friedmann, inflation, inflation éternelle, absence de frontière de Hartle–Hawking, trou noir euclidien, fonction d'onde de l'univers et histoires dépendant de l'observation.

Page unique (`index.html`), sans dépendance.
